# eledio.services — Ansible collection

This documentation describes the `eledio.services` Ansible collection: a set of roles intended to deploy and manage services on Debian-based systems (Raspbian / Raspberry Pi OS, Debian, Ubuntu).

Included roles:

- `common` — base system setup and essential packages
- `install_uv` — install the `uv` Python package manager system-wide
- `vpn` — deploy OpenVPN client configuration and manage systemd instance
- `st_link` — deploy ST-Link udev rules for unprivileged USB access
- `label_printer` — deploy a label-printer service and its configuration
